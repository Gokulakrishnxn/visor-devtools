V.I.S.O.R. isn't a post-run viewer: it **is** the harness. A local daemon drives the agent loop, executes tools, enforces guardrails and streams typed events to the GUI.

## The daemon

- Hono HTTP + WebSocket server on `127.0.0.1:4310`
- Per-launch session token on every request
- Streams `VisorEvent` messages; every span is also persisted to SQLite
- Instant offline replay of any past session

## Adapters

```ts
export interface AgentRuntimeAdapter {
  start(session: SessionConfig): AsyncIterable<VisorEvent>;
  resolveBreakpoint(spanId: string, decision: OverrideDecision): void;

}
```
