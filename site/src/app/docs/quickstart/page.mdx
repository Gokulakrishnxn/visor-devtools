export const metadata = { title: "Quickstart" };

<Warning>
The packaged `npx visor-devtools` command arrives in Phase 3. Until then, run V.I.S.O.R. from source.
</Warning>

<Steps>
  <Step title="Check your tools">
    You need **Node.js 20.19+** and **pnpm**. On macOS with Homebrew:

    ```bash
    brew install node pnpm
    ```
  </Step>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/Gokulakrishnxn/visor-devtools.git
    cd visor-devtools
    pnpm install
    ```
  </Step>
  <Step title="Add your API key (optional)">
    Previews and tests run on the zero-cost `MockRuntimeAdapter`, so you can skip this. For live runs, copy the example file and add your key:

    ```bash
    cp .env.example .env
    # then edit .env
    ANTHROPIC_API_KEY=sk-ant-...
    ```
  </Step>
  <Step title="Start it">
    ```bash
    pnpm dev
    ```
    Open the URL the daemon prints (`http://127.0.0.1:5173/?token=…`) and click **Run mock session**. The daemon listens on `127.0.0.1:4310` only.
  </Step>
</Steps>

## Run against real Claude

Mock mode is the default and costs nothing. When you're ready for real runs, opt in and set a cap:

```bash
VISOR_RUNTIME=claude pnpm dev
```

<Warning>Live mode spends real money on your Anthropic account. Every tool call still passes through V.I.S.O.R.'s rules and pause cards first.</Warning>
