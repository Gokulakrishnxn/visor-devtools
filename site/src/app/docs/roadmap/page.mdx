V.I.S.O.R. is built in strict phases. Each phase ends at a gate and the next one only starts after review.

<Steps>
  <Step title="Phase 1 · Foundation">
    Repository, strict TypeScript, Tailwind UI foundation, Drizzle schema, `MockRuntimeAdapter`, and green CI (typecheck, lint, test, build).
  </Step>
  <Step title="Phase 2 · Three GUI prototypes">
    Three clickable designs on mock data: **Studio Tri-Pane**, **Linear Focus** and **Mission Deck**, at `/preview/1`, `/preview/2` and `/preview/3`. One is chosen as the official interface.
  </Step>
  <Step title="Phase 3 · Core build">
    Real Claude Agent SDK and MCP runtime, SQLite persistence, the verified cost and credit engine, mid-flight overrides, deep inspection, and a native macOS `.dmg` with the `vhud` launcher.
  </Step>
</Steps>
